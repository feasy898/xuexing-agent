### 2.3 KP 粒度判定规则（化学专用）

一条 KP = **一个"可独立命题 + 可独立诊断"的知识/技能单元**。判定用下面 5 条规则（**全部满足**才建；**任一命中**才建）：

| 规则 | 内容 | 化学示例 |
|---|---|---|
| R1 可测性 | 能落成一个明确的对错/给分点 | 「相对分子质量的含义及应用」✅；「物质的多样性」❌（太大） |
| R2 前置完整性 | 它的 prereqs 都在更低年级或更低 layer | 「电解平衡常数」需 `hs2.reacp.01`+`hs2.reacp.02` ✅ |
| R3 单一诊断 | 学错原因唯一，误判不重叠 | 「离子反应」✅；「离子反应 + 离子方程式书写」❌（后者是技能，不同层） |
| R4 教材落点 | 能落到教材某一"节"的连续段落 | 「氧化还原反应的本质是电子转移」落 必修二第三章第一节 ✅ |
| R5 命题承载 | 真卷里至少能生成 1 道真题形态的题 | 「化学与可持续发展」只能生成 `project` 类开放题 → 降级为 cluster，不建 KP |

**化学特有的三条切分经验**（写给 K12-2 的执行人）：

1. **"知识"与"技能"分层**：*知道氧气的性质*（知识 KP）与*用排水法收集氧气并检验*（技能 KP）分开。技能 KP 用 `form=experiment / equation_writing` 出题。
2. **宏观/微观/符号三重表征拆开**：《物质的组成与结构》整块的三重表征是**三个 KP 家族**（宏观=物质分类/性质；微观=分子原子离子；符号=化学式/化合价/相对分子质量），不要合成一个"物质组成"大 KP。
3. **"反应类型"是独立 KP 层**：化合/分解/置换/复分解**不是**四个 KP，而是"4.2.1 化学变化的特征及化学反应的基本类型"这一个 topic 下的 4 个 KP，且它们共同挂在几乎所有具体反应 KP 的 prereqs 上（图里会形成高扇入，注意拓扑）。


- `cluster` 字段（对齐 math 的用法）：填**主题中文全名**，便于出卷器按主题配题。
- `prereqs` 建边规则：**只允许** (低年级→高年级) / (同一 topic 内低序号→高序号) / (必修→选必) / (选必→选修)。**跨主题横向边**（如"物质的量"(1.3) → "溶液浓度计算"(2.2)）必须显式声明并加注释，因为它是图里最容易成环的地方（见下）。
- **化学图谱的已知环风险点**（必须在 K12-2 审计里显式检查）：

  2. `氧化还原反应`（必修二 2.2）与 `电解/电镀`、`原电池`（选必模块1）双向关联。
  3. `离子反应/离子方程式`（必修二 2.3）↔ `电解质与离子平衡`（选必模块1 3.1）——前者是后者的必要但不充分条件，建边要单向。

## 3. 题型目录

### 3.0 口径（内核三型 + form 标签，全学科统一风格）

- **内核三型 `kernel_type`**：只有 `choice` / `fill` / `solve` 三个值。
- **`form` 标签**：小写英文 snake_case，语义指向**呈现形态 / 任务类型**而非学科内容。风格约定（沿用 `physics.md` §3.0 的 12 个，全学科共享）：

  `mcq_single`、`mcq_multiple`、`fill_blank`、`draw_diagram`、`read_instrument`、`experiment`、`experiment_data`、`calculation`、`comprehension`、`essay`、`open_design`、`project`

- **化学新增 2 个（请 K12-2 登记进全学科词表）**：
  - `equation_writing` —— 化学方程式 / 分子式 / 离子方程式 / 电荷式 / 有机结构简式 / 配平的书写。判分内核特殊（配平、条件、"↑↓"、状态、过量），`fill_blank` 表达不了。
  - `process_flow` —— 工业生产 / 工艺流程题：读流程框图 → 填"物质 / 条件 / 操作 / 分离方法 / 目的"。

  命名规则不变：`form` 描述**呈现形态**，`kernel_type` 描述**判分内核**。例："化学方程式书写"=`fill`+`equation_writing`；"工艺流程题"=`solve`+`process_flow`；"实验探究设计"=`solve`+`experiment`。

### 3.3 专章：实验题与工艺流程题（本次重点研究方向）

#### 3.3.1 实验题的三层拆解

化学"实验题"不是单一形态，出题时必须落到下面**三层之一**，否则无法配 `scoring_points`：

| 层 | 名称 | 判分内核 | form | 生成要点（可自动化的骨架） |
|---|---|---|---|---|
| L1 | **操作层**：仪器选择 / 装配 / 顺序 / 错误后果 | `fill` | `experiment` | 器材池 × 装置图池；错误操作 → 后果配对表（如"试管未略向下倾斜→液体流出/管口炸裂"） |
| L2 | **分析层**：现象 → 结论 / 检验 / 分离 / 制备 | `solve` | `experiment` | 现象字典 + 特征反应表（课标「1.3 化学实验」：「能根据物质性质的差异选择物质分离的实验方法；能根据物质的特征反应和干扰因素选取适当的检验试剂」） |
| L3 | **设计层**：给定目的 → 设计方案并评价 | `solve` | `open_design` 或 `experiment` | 目的 → (原理, 试剂, 装置, 步骤, 现象, 结论) 六元组；必须能生成多解并配 `acceptable_variants` |

**采分点建议**（K12-C「答案三层准确性」的落法）：
- L1：`scoring_points` = 操作名（1 分/项），错一步即错。
- L2：`scoring_points` = 现象（1）+ 结论/方程式（1），**允许表述变体**（`acceptable_variants`：如"变红/由无色变红"都算）。
- L3：`scoring_points` = 原理（1）+ 关键操作（1）+ 安全/环保（1）；`acceptable_variants` 必填（方案不唯一）。

**素材池（法定，可信度：高）**：义教 8 个必做实验（§1.3）+ 高中 18 个必做实验（§1.5）= **26 个法定实验素材**。任何实验题变体应能回指其中之一或课标「学习活动建议」中列举的实验探究活动。

#### 3.3.2 工艺流程题的骨架（`process_flow`）

**统一 7 槽模板**（出卷器可据此生成变体，槽位留空即成填空点；槽号用 `P1–P7`，避免与 §6 的来源编号 S1–S11 冲突）：

| 槽 | 提问 | 常用 form |
|---|---|---|
| P1 原料/起始物 | "流程中 A 是……" | `fill` + `process_flow` |
| P2 加入试剂 | "步骤②中加入的试剂为……" | 同上 |
| P3 分离操作 | "分离 X 与 Y 的操作为……"（过滤/分液/结晶/蒸馏/萃取） | 同上 |
| P4 条件 | "反应需在……条件下进行"（温度/压强/催化剂） | 同上 |
| P5 目的/原因 | "该步骤的目的是……""用……而不用……的原因是……" | `solve` + `process_flow` |
| P6 方程式书写 | 写关键步骤的化学方程式 | `fill` + `equation_writing` |
| P7 STS 评述 | "该工艺的绿色化学体现在……" | `solve` + `essay` |

**初中 vs 高中差异**（依据：初中只到"除杂/分离/转化"的浅层工艺；高中课标主题1 明写"化工生产模拟实验（如制硫酸、制硝酸）"）：

| 维度 | 初中（J-11） | 高中（S-08） |
|---|---|---|
| 工序数 | 3–5 | 6–10 |
| 变式来源 | 除杂/净水/粗盐提纯/金属冶炼/侯氏制碱 | 工业合成（合成氨/硫酸/硝酸/电石/海水提溴镁） |

| 常见陷阱 | 试剂顺序、过量、过滤洗涤顺序 | 副反应、循环利用、原子利用率、能耗/环保评价 |

### 5.4 教材锚点使用规则

1. `textbook_ref` 是**二级锚**，`topic_id` 是一级锚。二者**多对多**（一个课标条目常跨 2–3 个教材节，一个教材节常跨 2 个课标条目）→ 必须建成 `kp ↔ section` 的边表，不要在 KP 上放单一 `textbook_ref` 字符串。
2. 人教版教材**不在**国家中小学智慧教育平台的免费电子教材之列（该平台对化学只提供义务教育/普通高中"教科书"分册元数据与部分页面预览，**不提供全文可下载 PDF**），因此**章节级锚点的权威来源只能是正版教材本身或教辅资料**——本文件 §5.3 的一手来源是平台预览页图（官方资产），可信度中；未取到节标题的，落地前须核对实体书。
3. 初中「五四学制全一册」册不进入海南 profile，仅进 `variant` 库。
