## 1. 课标结构 —— 学段划分、领域/主题/模块清单

### 1.1 义务教育《地理课程标准（2022 年版）》：**不按学段切分，按「空间尺度」切分**

**这是本次研究最重要的结构性发现，与 ask 中「按学段」的组织预设不同，特此置顶说明。**

课标「四、课程内容」开篇（印刷 p7，PDF p14）原文核对：

> 「地理课程从**空间尺度**的视角对课程内容进行组织，按照"**宇宙—地球—地表—世界—中国**"的顺序，
> 引导学生认识人类的地球家园。地理课程以认识宇宙环境与地球的关系、地理环境与人类活动的关系为
> 两条主要线索，并将**地理实践活动和地理工具的运用贯穿其中**，形成将学科知识与学科活动融为一体
> 的课程内容结构（图 2）。」

「五、学业质量（二）学业质量描述」开篇（印刷 p31，PDF p38）再次确认：

> 「**义务教育地理课程内容分为认识全球、认识区域两大部分，共五个主题，地理工具和地理实践贯穿其中。**」

**推论（C 级）**：2022 版义教地理课标**全文没有「第一/第二/第三/第四学段」的内容要求分块**，
学段维度只在极少数语境出现。学段（年级/册次）映射**必须**取自实际教材分册，不能从课标推导。
这直接决定了 §2 的 KP 建模方式：KP 的**第一层主键是课标主题/条目，不是年级**。

### 1.5 高中：核心素养与学业质量

**核心素养（印刷 p4-5，PDF p7-8）**：**人地协调观、综合思维、区域认知、地理实践力** ——
与义教 2022 **同名同义**（表述逐字一致），差别在高中增加了各素养的具体内涵段与
附录 1「内涵与表现」、附录 2「水平划分」。

**学业质量（印刷 p28-31，PDF p31-34）**：
- 三维度：「**综合性、区域性、实践性**」。综合性=地理要素/地理过程/人地相互影响；
  区域性=区域整体特征/区域差异/区域联系/区域发展；实践性=实践活动方案设计与实施及过程品质能力。
- **三级水平（表 1）**：水平 1 / 2 / 3，每级 3 条（**-1 综合性 / -2 区域性 / -3 实践性**），
  共 **9 条学业质量描述**。水平 1 的情境是「**结构良好**的地理情境」，水平 2、3 是「**结构不良**的
  地理情境」。
- 应用：「学业水平考试分为**合格性考试**和**等级性考试**。地理学科学业质量水平 1 是普通高中学生
  毕业应当达到的要求，也是地理学科学业水平**合格等级**的划定依据。地理学科学业水平**等级性
  考试不超过学业质量水平 3**。」

### 2.4 组织方式草案要点

1. **主键用课标条目，不用教材章节**。义教课标不设学段，若以教材章节作主键，换教材即失效。
   建议 KP 主键 = `(stage, domain, theme, section, kp_seq)`，`textbook_ref` 作为**弱引用属性**。
2. **区域案例独立成 `region_case` 维度**。课标对世界/中国区域案例给了硬性数量下限
   （≥1 大洲+3 地区+4 国家；京港澳台+≥5 区域），案例 KP 应可按案例检索、替换、轮换。
3. **`task_type` 用课标「任务指向」四类**（识别 / 比较 / 综合分析 / 工具运用，印刷 p40）。
   这是课标给出的官方能力分类，比自拟标签更有依据。
4. **素养标签 `kc_targets` 两学段可共用**（人地协调观/综合思维/区域认知/地理实践力）。
5. **义教与高中的 KP 桥接**：义教「地球的运动」→ 高中选必 1「地球运动的地理意义」；
   义教「世界气候类型分布」→ 高中地理 1「大气」+ 选必 1「气候」；义教「认识分区」→
   高中选必 2「区域发展」。桥接关系建议写进 `prereq_kp_ids` 或新建 `bridges` 表。

### 4.5 卷型 E：课标内嵌官方样题（义教 · 综合题）— 时间权重 1.0（唯一可核的义教地理官方题）

```
textbook_key = f"{publisher_code}-{edition_code}-{stage_code}-{volume_code}-{unit:02d}-{section:02d}"
例：PEP-2022-J-C7A-01-01   /  PEP-2017-S-BX1-03-02
```

### 5.4 KP ↔ 教材的映射规则（建议）

1. **KP 不以 `textbook_ref` 为主键**（换版即失效）。`textbook_ref` 存为数组，允许一个 KP 挂多个
   版本的多条引用。
2. **每条 KP 必须带 `textbook_ref.verified` 标记**，图谱建设初期大量为 `false`，
   前端应据此显示「未校准」徽标。
3. **映射粒度建议到「节」**。课标内容要求 bullet 常对应教材的 1–2 个「节」；过粗（到章）会丢失
   诊断分辨率，过细（到知识点）会与教材强耦合。
4. **跨学科主题学习与地理实践**不挂在具体教材册次上，建议 `textbook_ref: null` +
   `cross_refs: [跨学科主题学习, 地理实践]`。
5. **海南区域案例（家乡）**建议 `textbook_ref` 指向「本省/本县补充材料」而非教材，
   用 `region_case: 县一级行政区` 标记。
