# 渠道合规触发矩阵（channel-gates）

> 性质：**研究资产**（签署测试卡 TC-6，2026-10-08；裁定 D-1）。
> 立场声明：**本轮不办理任何备案**（见 §6）。本文只做「触发条件研究」，
> 帮助判断「什么动作会触发哪一关」；任何备案/申报的启动都属 owner 商业
> 决策，且按 D-1 裁定须先重新提交签署。
> 引用纪律：法规只引名称、发布机关与官方门户 URL；条文编号与细节未经
> 逐条核对的一律标「待核实」，不编造。

## 1. 渠道定义（对应 D-1 三选项）

| 渠道 | 定义（本矩阵语境） | 当前裁定状态 |
|---|---|---|
| 静态卷（A，已裁定优先） | 预生成的可打印卷子文件（HTML/PDF/答题卡），离线分发，无在线服务、无数据回传 | 本轮唯一建设渠道 |
| 教培机构（B） | 产品被线下/在线教培机构接入使用（内网部署或账号接入） | 本轮不做 |
| 小程序（C） | 面向公众（含未成年人）的微信小程序在线服务 | 本轮不做 |

## 2. 五关 × 三渠道触发矩阵（15 格）

判定口径：**适用**=该组合通常触发该关；**不适用**=按当前形态与红线
（不采集学生数据、不做在线服务）通常不触发；**待核实**=依赖具体形态或
条文细节，办理前必须逐条核实。

| 关 | 静态卷 | 教培机构 | 小程序 |
|---|---|---|---|
| 双减（学科类校外培训治理） | 待核实：纯试卷文件分发通常不构成「校外培训服务」，但学科类培训材料监管精神覆盖教辅内容；一旦经机构用于培训或涉收费即转适用 | 适用：机构用本产品开展学科类培训即落入双减监管（培训资质、材料合规、收费监管），产品方需配合材料合规与留痕 | 适用：面向公众提供线上学科培训服务即属线上校外培训，需培训资质与相关备案后才可上线 |
| 生成式人工智能服务备案（《生成式人工智能服务管理暂行办法》） | 不适用：静态卷是预生成文件的离线分发，未「向境内公众提供生成式服务」；前提是永不开放在线生成功能（触发条件 (c) 一旦成立即转适用） | 待核实：机构内网/本地部署、不对公众提供服务，通常不触发「服务提供者」备案；若经 API 向机构学员在线输出生成内容，则服务提供/技术支持角色须逐条核实 | 适用：对公众提供在线生成/讲解功能即需履行生成式 AI 服务备案（涉舆论属性的按属地网信程序） |
| 个人信息保护法（PIPL） | 不适用：本渠道零采集零回传（红线 + TC-4 卷包零回传元素门）；一旦收集任何学习者个人信息即转适用（触发条件 (b)） | 适用（以采集为前提）：产品若采集学习者数据即成个人信息处理者（告知同意、最小必要、安全保管、未成年人信息加重义务）；维持「不采集」则不触发 | 适用：上线即涉账号、设备与使用记录等个人信息处理，须完整履行 PIPL 义务并有隐私政策 |
| 未成年人模式（《未成年人网络保护条例》等） | 不适用：非在线服务，不涉网络产品未成年人模式要求；内容导向仍须对齐教材与课标（产品内控，非本关） | 待核实：机构线下/内网使用不触发；若产品以在线学习平台形态供未成年人使用即须对齐未成年人模式要求 | 适用：面向未成年人的在线服务须支持未成年人模式（使用时段/时长管理、内容安全等） |
| 教育移动互联网应用程序备案（教育 App） | 不适用：纸质/文件分发不是移动应用程序 | 待核实：若以移动 App 形态向机构提供则按办法备案；Web 端与纸质形态通常不在办法射程 | 待核实：小程序形态是否按「教育移动应用」口径备案须核实（实践中教育类小程序在微信平台另需提供资质/备案材料；备案平台 app.eduyun.cn） |

## 3. 各关：触发条件、所需材料、办理顺序

### 3.1 双减
- 触发：向未成年人提供学科类培训服务，或产品被培训机构用于学科培训并收费。
- 所需材料（概要，办理时逐项核实）：办学许可证/线上培训备案（按属地教育部门口径）、培训材料备案与审核、资金监管与收费公示、从业人员资质。
- 顺序：先定商业模式（D-2），再按渠道判定是否构成「培训服务」，最后按属地教育部门要求逐项办理。**未经 owner 重新签署不得启动。**

### 3.2 生成式人工智能服务备案（《生成式人工智能服务管理暂行办法》，2023-07 公布、2023-08-15 施行）
- 触发：向境内公众提供具有舆论属性或社会动员能力的生成式 AI 服务（含通过 API 向公众提供）。
- 所需材料：属地网信备案程序材料、安全评估与语料/内容安全制度文件、算法相关申报（涉算法推荐的按《互联网信息服务算法推荐管理规定》另核，待核实）。
- 顺序：先冻结服务形态（是否有面向公众的在线生成），再属地网信履行备案。静态卷渠道保持离线即可长期不触发。

### 3.3 个人信息保护法（PIPL，2021-08-20 通过、2021-11-01 施行）
- 触发：处理自然人个人信息（采集、存储、使用任何学习者/家长数据）。
- 所需材料：隐私政策、告知同意机制、最小必要与安全措施说明、（涉未成年人）监护人同意与专门规则。
- 顺序：先确立「不采集」红线的工程落实（本仓已有 G0-5 零网络默认与 TC-4 零回传门），任何采集需求出现即先过本关。

### 3.4 未成年人模式（《未成年人网络保护条例》2023-10 公布、2024-01-01 施行等）
- 触发：面向未成年人提供网络产品/服务。
- 所需材料：未成年人模式功能说明（时段/时长/内容安全）、内容审核制度。
- 顺序：随在线渠道（小程序/在线机构服务）启动一并设计，先于上线。

### 3.5 教育移动互联网应用程序备案（教育部等六部门《教育移动互联网应用程序备案管理办法》，2019）
- 触发：以教育移动应用形态提供服务（App/小程序口径待核实）。
- 所需材料：ICP 备案与等保基础、开发者资质、内容与数据安全承诺，经 app.eduyun.cn 平台办理（备案为常态线上办理）。
- 顺序：与小程序/机构 App 形态立项同步启动；纯静态卷与 Web 形态不触发。

## 4. 重新签署硬门（抄录 D-1 裁定，2026-10-08）

签署代理 D-1 裁定：本轮合规五关不启动任何备案或申报，只产出本触发矩
阵；以下任一条件成立前，对应的关必须先办完，并重新提交签署：

- (a) 对公众或未成年人开放任何在线服务（含现有作答 Web 闭环 63b29d3 和教师批改端 d4f5f4d 的对外部署）；
- (b) 采集或存储任何真实学生数据；
- (c) 对公众开放在线 LLM 生成功能；
- (d) 收费或签约 B2C、教培机构合作。

## 5. 《人工智能生成合成内容标识办法》对静态卷的适用性评估

该办法由国家网信办、工信部、公安部、广电总局于 2025-03-07 联合发布
（国信办通字〔2025〕2号），2025-09-01 施行；要求对人工智能生成合成内容
添加标识（来源：国家网信办官网 www.cac.gov.cn）。

对本项目的适用判断：
- 静态卷内容含 AI 辅助生成并经校验的题目，属生成合成内容传播场景的
  边缘形态（文件分发、非平台服务）——**待核实**：办法及配套强制性
  国家标准对「离线文件分发」形态的显式/隐式标识技术要求（标准名称与
  编号待核实，不在本文引用）。
- 已落地的保守对齐（TC-4，无需等核实即可保持）：学生卷与教师卷卷头
  显式标注「本卷题目由 AI 辅助生成并经校验」及「题目为原创（含 AI 辅助
  生成并经校验），对齐课标与教材，非真题」——显著、逐卷、不可关闭。
- 后续动作：对外分发启动前（触发条件 (d) 或 (a) 任一成立），按办法
  全文与配套标准逐条核对显式/隐式标识形态，**待核实项清零后方可分发**。

## 6. 本轮不办理任何备案

- 本轮（签署测试卡 TC-1..TC-8 开发轮）**不办理任何备案或申报**：
  不提交双减相关申请、不做生成式 AI 备案、不做教育 App 备案、不启动
  任何等保/ICP 申报动作。
- 本文是唯一合规产出；渠道建设范围严格限于 D-1 裁定的静态卷（离线
  文件），不部署任何在线服务、不采集任何真实学生数据。
- 四条触发条件（§4）任一成立即冻结分发并重新提交签署。
